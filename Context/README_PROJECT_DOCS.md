## How to use these documents

These files are project control documents, not loose notes.

Before implementing a feature:
- read the relevant sections;
- plan the feature;
- design it;
- review leakage/reproducibility implications;
- implement;
- test;
- validate;
- freeze.

If a methodology change is required, update the relevant document first and explicitly version the protocol.
