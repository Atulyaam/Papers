# Logging, Checkpoints, and Provenance

## 1. Logging

No long-running production/experiment code should depend on bare `print()` for observability.

Use structured logging.

Logs live under:

```text
results/logs/<EXPERIMENT_ID>/run.log
```

Every experiment log should capture:

- experiment ID
- timestamp
- stage
- seed
- configuration reference
- dataset reference
- status
- warnings
- errors
- elapsed time
- key counts/shapes
- completion state

## 2. Checkpoints

Each experiment that trains artifacts receives a dedicated folder:

```text
results/checkpoints/<EXPERIMENT_ID>/
```

Examples:

```text
EXP_OOF_STACK_SEED42/
├── dt.joblib
├── rf.joblib
├── svm.joblib
├── nn.pt
├── meta_learner.joblib
├── encoder.joblib
├── scaler.joblib
├── mi_selector.joblib
├── selected_features.json
└── metadata.json
```

AE example:

```text
EXP_AE_SEED42/
├── autoencoder.pt
├── scaler.joblib
├── threshold.json
└── metadata.json
```

## 3. No Metrics-Only Runs

Metrics are not considered a sufficient reproducibility artifact.

When practical, preserve:

- fitted models
- preprocessing state
- selected feature list
- threshold
- predictions
- configuration
- metadata

## 4. Config Snapshot

Every experiment result directory must contain the exact configuration used.

Example:

```text
results/metrics/EXP_OOF_STACK_SEED42/
├── metrics.json
├── predictions.csv
├── config.yaml
└── metadata.json
```

## 5. Provenance Metadata

Metadata should record:

- experiment ID
- Git commit
- config hash
- dataset file hashes
- seed
- timestamp
- Python version
- major package versions
- selected feature list reference
- withheld subclass reference
- protocol version

## 6. Dataset Fingerprint

Raw dataset files are fingerprinted with SHA-256.

Store hashes under:

```text
data/audit/file_hashes.json
```

## 7. Git/FREEZE Rule

Every FREEZE creates a Git commit.

Recommended naming:

```text
freeze: EXP_BASE_DT_V1
freeze: EXP_PREPROCESSING_V1
freeze: EXP_OOF_STACK_V1
freeze: EXP_AE_V1
```

Optional tags may use the same experiment identifier.

## 8. Result Integrity

Result files must be generated by evaluation code.

Do not manually type performance numbers into official result files.
