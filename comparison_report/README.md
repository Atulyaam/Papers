# Comparison Report

This directory contains the comparative analysis between the **Main Research Project** (Sprint 1–8) and the **Supplementary Original-Split Benchmark** (Sprint 9).

## Contents

- [main_vs_original_benchmark.md](./main_vs_original_benchmark.md) : The complete comparison report detailing protocol differences, metric breakdowns, and research observations.
- [comparison_table.csv](./comparison_table.csv) : A high-level CSV summary table for quick import/reference.
- [provenance.md](./provenance.md) : The authoritative source file, experiment ID, and protocol for every metric used in the report.
- [comparison_metadata.json](./comparison_metadata.json) : Automation metadata mapping the analyzed experiment boundaries.

*Note: All files have been explicitly encoded in UTF-8 to preserve standard mathematical notation.*
